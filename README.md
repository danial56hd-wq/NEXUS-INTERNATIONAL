## 🇬🇧 English

### Overview

**NEXUS-INTERNATIONAL** is an all-in-one scientific web platform that combines an AI assistant, interactive satellite maps, scientific charts, a symbols palette and a built-in developer studio, all in a **single HTML file**. It is built with pure HTML, CSS and JavaScript (no framework, no build step) and designed to run smoothly on mobile phones.

It works with **free AI models** from three providers (OpenRouter, Groq and Google Gemini). You bring your own free API key, and it stays on your device.

🔗 **Live app:** https://nidalwatfa.codeberg.page/NEXUS-INTERNATIONAL/

### ✨ Key Features

| Module | What it does |
|---|---|
| 🔭 **Explore** | Main dashboard and entry point to the platform |
| ∑ **Symbols** | Palette of scientific and mathematical symbols, tap to copy or insert |
| 🌍 **Maps** | Interactive Leaflet map with satellite imagery and place labels, plus "My location" |
| 📊 **Data & Charts** | Line, bar, radar, pie and scatter charts, plus geometric and architectural shapes (circle, triangle, arch, wave) with max / average / min markers and a live preview |
| 🧠 **AI** | Ask the AI to generate scientific content and drawings |
| 💬 **Chat** | Scientific conversation with the selected model, read-aloud (text-to-speech) and voice input |
| ⚙️ **Console** | Built-in console with commands: `help`, `clear`, `models`, `keys`, `status`, `version` |
| 👑 **Developer** | Code editor (JavaScript, Python, HTML, CSS, Dart, C++, Java, SQL, Bash), run JavaScript, AI code completion and explanation, live HTML preview, download the file |

**More highlights**

- 🤖 **9 free models** from OpenRouter, Groq and Google Gemini, with an official link for each model inside the app
- 🔐 **Privacy first:** API keys are stored only in your browser's `localStorage` and are never exported with the file
- 📤 **Share and export:** native share, WhatsApp, Telegram, email, copy link, download the whole app as one HTML file, and save your session as JSON
- 🌗 Light and dark themes
- 🌍 Automatic language and direction detection (Arabic RTL / English LTR)
- 📱 Mobile-first design, built and maintained entirely from a phone
- ⚡ Zero dependencies to install; only a few libraries are loaded from CDNs (Leaflet, Chart.js)

### 🚀 How to Use

1. **Open the app:** https://nidalwatfa.codeberg.page/NEXUS-INTERNATIONAL/
2. **Get a free API key** from at least one provider (see the table below).
3. Tap **🔑 API**, paste your key, then save. The indicator turns green when a key is active.
4. Tap **🤖 Models** and choose a model. The default is *OpenRouter Free Router*.
5. Open **💬 Chat** and start asking, or explore **Maps**, **Data**, **Symbols** and **Developer** tools.

> ⚠️ Free plans have usage limits set by each provider. The app shows OpenRouter's free tier as 50 requests per day. Check each provider's page for current limits.

### 🛠️ Tech Stack

- **Core:** HTML5, CSS3, Vanilla JavaScript (Vanilla Evolution: power in simplicity and performance)
- **Maps:** [Leaflet](https://leafletjs.com) 1.9.4 with Esri World Imagery tiles
- **Charts:** [Chart.js](https://www.chartjs.org) 4.4.1 with the annotation plugin
- **Fonts:** Orbitron, Cairo, JetBrains Mono (Google Fonts)
- **AI APIs:** OpenRouter, Groq, Google Gemini (called directly from the browser)

### 📦 Deployment

The project is one file: `index.html`. To host your own copy:

1. Put `index.html` in the root of any static host (Codeberg Pages, GitHub Pages, Netlify, etc.).
2. On Codeberg Pages, place it in the `pages` branch of your repository.
3. Open the published URL. No build or install is needed.
